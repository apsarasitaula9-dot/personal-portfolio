# Portfolio Assets Directory

Place your profile photo here!

## How to add your real profile photo:
1. Name your photo file: `profile.png` (or `profile.jpg` / `profile.jpeg`).
2. Save it directly in this folder: `assets/profile.png`.
3. For best results, use a portrait cutout or transparent background (PNG), or a clean vertical photo.
4. The website will automatically display your photo with gold rim lighting, organic morphing backdrop, and smooth blending.
